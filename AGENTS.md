# Project instructions

## Release scope

The maintainer has chosen GitHub Releases without a paid Apple Developer
account. Skip Developer ID signing and Apple notarization. Do not ask the
maintainer to purchase an account or report those steps as release blockers
when assessing progress or how close Merlin is to completion.

Finish implementation, testing, packaging and installation documentation
for that release scope. Free ad-hoc signing, if required to run on Apple
Silicon, is compatible with this decision. See [the release policy and
installation guide](docs/RELEASE.md). This decision supersedes older signing
requirements in historical plans unless the maintainer explicitly changes it.
